# Reformer

This is the project from [The Odin Project](https://github.com/TheOdinProject) curriculum — a simple user registration and editing application built with **Ruby on Rails**, focusing on Rails forms, form handling, validations, and CRUD operations.

## Features

- Create users
- Edit and update users
- Validate user input
- Display validation errors
- Handle form submissions
- Protect forms against CSRF

## Skills Learned

### Ruby on Rails

- Rails forms and form helpers
- Form handling and submissions
- Model validations
- Strong parameters
- RESTful routing
- CRUD operations
- CSRF protection
- Turbo

## Challenges

- Understanding how Rails forms work
- Understanding form submissions and HTTP methods
- Connecting forms with models and controllers
- Handling validation errors
- Understanding CSRF protection
- Getting familiar with Rails conventions
